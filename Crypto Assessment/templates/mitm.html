Demonstration of how an unauthenticated Diffie–Hellman exchange is completely compromised by Eve.

MITM ATTACK SUCCESSFUL
Channel Fully Hijacked

The original Diffie–Hellman exchange does not authenticate the public values, allowing an attacker to substitute their own public values.

Alice established a secret key with Eve ($K_{AE}$), while Bob established a separate secret key with Eve ($K_{BE}$). Alice and Bob believe they are communicating securely, but neither shares a direct key ($K_{Alice} \neq K_{Bob}$).

Active Interception Topology: Alice → Eve → Bob
Alice
Victim A
Private Key: a = 6
Original Sent Value: A = 8
Received Public Value: B_Eve = 13 Substituted
Computed Shared Key:
K_Alice = (B_Eve)^a mod p = 13^6 mod 23 = 12
Alice thinks 12 is shared with Bob!
Eve (Attacker)
Active MITM
Intercept & Substitute:
1. Alice sends A = 8 → Eve intercepts.
2. Eve transmits A_Eve = 17 to Bob.
3. Bob sends B = 19 → Eve intercepts.
4. Eve transmits B_Eve = 13 to Alice.
Eve Private (Alice): e_2 = 9
Eve Private (Bob): e_1 = 7
Key with Alice: K_EA = A^e_2 mod p = 8^9 mod 23 = 12
Key with Bob: K_EB = B^e_1 mod p = 19^7 mod 23 = 18
Eve can decrypt & modify traffic in both directions!
Bob
Victim B
Private Key: b = 15
Original Sent Value: B = 19
Received Public Value: A_Eve = 17 Substituted
Computed Shared Key:
K_Bob = (A_Eve)^b mod p = 17^15 mod 23 = 18
Bob thinks 18 is shared with Alice!
Key Asymmetry Proof

In normal Diffie–Hellman, Alice and Bob calculate the exact same secret. In this MITM attack:

Alice's Secret Key (K_Alice): 12
Bob's Secret Key (K_Bob): 18
Alice Key == Bob Key? FALSE (12 ≠ 18)
Eve's Key with Alice (K_EA): 12 (Matches Alice)
Eve's Key with Bob (K_EB): 18 (Matches Bob)
