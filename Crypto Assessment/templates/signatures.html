How Asymmetric Cryptography Defeats Man-in-the-Middle Attacks

In an unauthenticated DH exchange, Eve can freely fabricate $A_E$ and $B_E$ because no mathematical binding exists between the public values and the identity of the sender. With digital signatures, Alice computes a digital signature $S_A = \text{Sign}_{SK_A}(A)$ using her secret private key $SK_A$. Because Eve does not possess $SK_A$, if Eve attempts to substitute $A$ with $A_E$, she cannot produce a valid signature for $A_E$. When Bob attempts verification using Alice's known public key $PK_A$, the signature test fails, and Bob immediately halts communication.
